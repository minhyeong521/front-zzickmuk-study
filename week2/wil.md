# 프론트엔드 2주차

- 화면안에 구조 있음
- 코드 안에 화면의 구조를 보는 방법: React

## React
- UI를 만들기 위한 도구
- 프로그래밍 언어가 아님, JS 라이브러리임
### Library
- 필요한 것을 찾아서 활용
- 다른 프로그램 안에서 가져다 사용할 수 있도록 한 코드 모음

## 화면 표현
- 프로필, 이미지, 액션, 콘텐트 등 구조가 있음
``` const images = post.querySelectorAll(".post-images")```
- 꺽쇠 <> , {}
- 리액트에서는 ```<header></header>```이런 식으로 구조를 보기 편함
- JSX: JS 안에서 UI를 표현하기 위한 문법(```<button>좋아요</button>```)
	- html과 비슷한데 완전히 같지는 않음
- const: 한번 값을 넣고 다른 값으로 재할당 안할 때 사용
- 변수나 JS 표현식 집어 넣을 때 중괄호 사용 ```<h2>{fish}</h2>```
- 사용자한테 보여주는 말을 다르게 할 수 있음

## 화면을 보는 눈
- 무엇을 만들지 먼저 보여야 한다
- 과정이 중요
- AI를 써도 프롬포트에 내가 원하는 것을 구체적으로 잘 써야 된다
